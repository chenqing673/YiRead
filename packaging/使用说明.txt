YiRead · 译·读 — Windows 64 位免安装版

1. 将整个压缩包解压到可写目录（例如桌面或 D:\YiRead）。
2. 双击 YiRead.exe，默认浏览器会自动打开阅读界面。
3. 使用期间保留服务窗口，关闭窗口即停止服务。

无需安装 Python、Node.js 或 PDF 处理依赖。请保留 _internal 文件夹。
不要直接从压缩包内运行程序。
需要 Windows 10/11 64 位及系统已有的浏览器。

文献、笔记、译文和设置会保存在 YiRead.exe 旁的 data 文件夹。
备份或迁移：先关闭服务，再复制整个 data 文件夹。
升级：解压新版，再将原 data 文件夹复制到新版程序旁。
发行包不包含任何个人文献或密钥。

导入、阅读在本机完成；翻译需要在设置中填写模型服务信息。
在线模型需要网络及 API 密钥，调用费用由服务商决定。
服务地址：http://127.0.0.1:8765
如果启动失败，请检查目录写入权限、8765 端口及 data/startup.log。

当前功能使用提示：
- 文献库使用条目展示。导入临时失败会自动重试；仍失败时点击“重试失败文件”，无需重新选择。
- “翻译全文”只决定范围；逐句翻译默认关闭，需要时在设置中单独开启。
- 连续阅读在正文相应位置保留可识别的原图、原表；“放大查看”核对细节，展开图表文字译文查看已有翻译。
- 翻译完成后可直接选择“原版排版”，无需先滚动浏览全文。排版更新或暂时失败时会保留完整译文并重试。
- 点击译文段落，再点击“译文”标题右侧的“记笔记”；书签在笔记窗口中勾选。已有记录从顶部“我的笔记 / 书签”查看。
- 切换排版、显示与放大原图表不调用翻译模型；导出译文是 Markdown 文字，不包含插入的原图表。
- 复杂无边框表格、扫描页及旧版整页译文需对照原 PDF 核对。

详细操作请双击同目录中的“用户使用说明书.html”，可离线查看；应用内“? 帮助”也提供操作说明。
