# 2026-10-09 · PDF 多栏阅读顺序修正

- 文字提取根据栏间空白识别阅读顺序，支持单栏、双栏、三栏及跨栏标题分区，避免同一高度的两栏文字交替翻译。
- 阅读、翻译任务和句子定位使用同一份排序后的原文。已有段落保留编号、译文和笔记关联；早期整页记录从 PDF 在内存中恢复原文顺序，不改写个人文件。
- 已生成的错序整页译文需要重新翻译；复杂表格和不规则排版仍需人工核对。
- 修正真实期刊窄栏间距漏判，按跨页宽分隔线重新识别摘要区与正文区的栏宽；旧文献以每行坐标排序，避免整段边界、页眉和行号影响识别，旋转页面转换回原始阅读坐标。
- 验证：10 项排版测试、26 项工作流测试、9 项 PDF 定位测试通过，使用临时文献和模拟翻译服务；另只读核对现有七页双栏期刊的段落顺序和编号，个人文献文件未改写。
