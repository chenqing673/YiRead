1. 应用介绍与使用条件

YiRead 是在自己电脑上运行的 PDF 文献阅读与翻译工具。可以导入文献、调用所配置的模型服务翻译文字，在原始 PDF 与译文之间定位，并记录笔记、书签及人工修订。

1.1 使用条件

项目要求或说明
操作系统Windows 10/11，64 位
运行环境免安装发行包已包含 Python 和 PDF 处理依赖
阅读界面使用电脑已有的浏览器
解压位置可写入的普通目录，例如桌面或 D:\YiRead
文件类型PDF，单个导入文件小于 50 MB
文字识别支持可提取文字的 PDF；扫描件需先自行 OCR
在线翻译需要网络、服务商接口信息及对应 API 密钥
本地模型可配置兼容接口；是否需要密钥取决于本地服务

导入、阅读已有译文、记笔记及人工修订不需要调用在线模型。翻译功能是否可用，取决于所配置服务的网络、权限和额度。

1.2 功能边界

  • 原始 PDF 中的图表、化学结构和公式保留原貌，阅读区以页面图像显示。
  • 译文导出是文字导出，不会生成保留原 PDF 排版的翻译版 PDF。
  • 自动文献信息提取可能不完整，需要核对。
  • 原文定位和逐句对应用于辅助阅读，不能替代对翻译内容的人工核查。
  • 术语表可以指导模型，但不能保证所有数值、术语和实验条件准确。

2. 解压、启动与退出

2.1 解压发行包

  1. 获取 YiRead-Windows-x64.zip。
  2. 右键压缩包，选择“全部解压”，或使用解压工具完整解压。
  3. 打开解压后的 YiRead 文件夹。
  4. 确认其中有 YiRead.exe 和 _internal 文件夹。

不要直接在压缩包预览窗口内运行。不要只复制 YiRead.exe；它需要旁边的 _internal 文件夹。

2.2 启动

  1. 双击 YiRead.exe。
  2. 程序出现本机服务窗口。
  3. 默认浏览器自动打开文献库。
  4. 使用期间保留服务窗口，可以将其最小化。

如果浏览器没有自动打开，手动输入：

http://127.0.0.1:8765

这是本机访问地址。同一台电脑通常只需启动一个 YiRead 服务。

2.3 退出

先保存正在编辑的笔记和修订内容。若有翻译任务，先点击“暂停”，等待已发出请求返回并保存，再关闭服务窗口。也可以在服务窗口按 Ctrl+C 停止。

关闭浏览器页面不会自动关闭后台服务。关闭服务窗口后，页面无法继续加载文献或保存到本机。

3. 第一次使用：完成一篇文献的阅读

  1. 启动应用：完整解压，双击 YiRead.exe。
  2. 导入文献：在文献库点击“导入 PDF”，选择一篇含可提取文字的 PDF。
  3. 配置翻译：打开“翻译设置”，选择服务商和模型，填写 API 密钥，选择目标语言并保存。
  4. 测试连接：点击“测试连接”。测试会发送少量文字，可能产生费用。
  5. 先翻译一页：打开阅读页，点击翻译按钮，选择“当前页”，确认范围和重译选项，再开始。
  6. 核对效果：选择“双语对照”，点击右侧译文，检查左侧原文和译文中的数值、术语及实验条件。
  7. 继续翻译：效果符合需求后，再翻译全文或指定页码。
  8. 记录笔记：点击一个译文段落，选择“记笔记”，输入内容并保存。
  9. 备份资料：关闭服务，复制程序旁的整个 data 文件夹。

4. 文献导入与管理

4.1 导入 PDF

在文献库点击“导入 PDF”，或将 PDF 文件拖入页面。支持同时导入多篇文献。

导入时程序保存 PDF 副本、提取文字并建立文献条目。相同内容的 PDF 会按文件内容检测重复；再次导入时返回已有文献，不创建副本。只修改文件名不代表文件内容发生变化。

若扫描件没有可提取文字，应先使用其他工具完成 OCR，再导入可提取文字的版本。YiRead 不会自动执行 OCR。

4.2 搜索、排序与筛选

在文献库搜索框输入关键词，可检索标题、文件名、作者、期刊、年份、DOI 和标签。可以按标题或导入时间排序，并按翻译状态、收藏及已读状态筛选。

例如，为同一课题添加一致的标签后，搜索该标签可以集中查看相关文献。

4.3 编辑文献信息

打开文献详情，可以修改标题、作者、期刊、年份、DOI 和课题标签，设置收藏或已读状态。

使用从 PDF 识别信息的功能后，请核对结果。该功能使用本机 PDF 元数据及首页文本，不会查询外部文献数据库。

4.4 删除与恢复

在详情页执行删除，会将文献移入回收站。回收站保留原 PDF、解析内容、译文、笔记和相关任务。

需要恢复时，在文献库打开“回收站”，找到文献并恢复。同编号文献已经存在时，程序不会覆盖已有文件。翻译执行中的文献暂不能删除，应先完成或暂停任务。

5. 翻译服务设置

5.1 设置字段

字段填写方法
服务商选择自己的模型服务商，或选择自定义兼容服务
API 基础地址填写服务商提供的基础接口地址，不重复填写 /chat/completions
模型选择名单中的模型，或填写服务商实际支持的自定义模型 ID
API 密钥填写在服务商平台申请的密钥
目标语言简体中文、英文或日文
术语表每行填写一个术语对应关系
逐句翻译需要更细的原文定位时开启
批量请求默认开启，将多个翻译单元合并到请求中
并发数默认 1，可选 2；频繁限流时使用 1

预置服务商包括 OpenAI、DeepSeek、通义千问、Kimi、智谱、硅基流动、Gemini、Groq、OpenRouter 和 Mistral。界面中的名单用于辅助配置，模型是否可用以自己的服务商账户为准。

5.2 申请并保存密钥

  1. 在设置页选择服务商。
  2. 使用“注册 / 登录”或“申请 API Key”入口访问服务商平台。
  3. 在平台上完成账户注册、所需开通及密钥创建。
  4. 将密钥粘贴到 YiRead 的密钥字段。
  5. 核对基础地址、模型和目标语言。
  6. 保存设置，再测试连接。

YiRead 不会自动注册服务商账户。当前应用使用 API 密钥翻译，不能自动复用其他客户端或浏览器中的登录状态。

5.3 基础地址示例

OpenAI 兼容接口的基础地址可能形如：

https://api.example.com/v1

不要填写成：

https://api.example.com/v1/chat/completions

应用会自动拼接请求路径。实际地址应按服务商提供的信息填写。远程接口要求 HTTPS；本机 localhost 或 127.0.0.1 服务可以使用 HTTP。

5.4 更换服务商或模型

  • 同一基础地址下只更换模型：密钥留空会保留已保存密钥。
  • 更换基础地址：保存时清除旧接口密钥，需要填写新服务对应的密钥。
  • 要删除已有密钥：使用“清除已保存密钥”选项后保存。
  • 本地无鉴权模型服务：可以不填密钥，但必须确保本地服务正在运行。

5.5 术语表

每行输入一条，例如：

workup = 后处理
equivalent = 当量
isolated yield = 分离收率
column chromatography = 柱色谱

建议统一同一课题中的术语。修改设置不会自动改写已有译文；需要应用新术语时，应对相应部分重译或人工修订。

5.6 段落翻译与逐句翻译

默认按段落翻译，保留较完整的上下文。开启逐句翻译后，程序保存更细的句子原文和 PDF 坐标；极长句会拆成片段。

逐句模式可能增加请求量并减少跨句上下文。已有译文不会因勾选此选项自动转换；“逐句对齐重译”会重新调用模型，可能产生费用。

6. 翻译任务与进度

6.1 选择范围

文献库的翻译按钮用于快速翻译全文。阅读页的翻译按钮可以选择：

  • 全文：处理整篇文献。
  • 当前页：处理当前阅读页。
  • 指定页码：填写起始页和结束页。

起始页不能大于结束页，页码应在文献页数范围内。

开始前务必检查“重新翻译所选范围”是否勾选。未勾选时默认继续未译部分；勾选后会重译范围内已有内容。文献已完成翻译时，该选项可能默认勾选。

6.2 查看进度

任务区域显示状态、所选范围内的完成数量、整篇文献已译比例及接口返回的 token 用量。所选范围完成与整篇全部完成是两个不同指标。

部分翻译完成后，已保存译文可以继续阅读。失败清单会显示未完成单元及原因，可以点击对应项定位。

多篇文献的任务按队列依次执行；文献内并发按设置使用 1 或 2。

6.3 暂停与继续

点击“暂停”后停止派发新请求。已经发出的请求可能继续返回并计费，返回结果会保存。请等待界面状态更新后再退出。

服务重启后，未完成任务会恢复为可继续的状态。继续或重试时会复用同一目标语言下已完成的翻译单元。

6.4 失败与补译

先查看失败原因，再处理：

  1. 核对地址、模型、密钥、网络和服务商额度。
  2. 修正设置并保存。
  3. 使用“继续翻译”“重试翻译”或“仅重试失败部分”。
  4. 如果只是补齐失败内容，避免勾选重新翻译整个范围。

临时限流和服务异常会有限重试；密钥或额度错误需先解决。超时重试可能再次产生调用费用。

修改目标语言后，新任务使用新语言；已经创建的排队任务使用创建时选择的语言。

7. 双语阅读与原文定位

7.1 阅读模式与显示调整

阅读页可切换“双语对照”“原文”和“译文”。双语模式左侧显示原始 PDF，右侧显示译文，两侧可以独立滚动。

使用页码选择跳转页面；PDF 缩放调整原页大小；A− / A＋ 调整译文字号。切换深浅主题后，原 PDF 保持白纸底色及原始图表颜色。

7.2 跟随译文

开启“跟随译文”后，滚动或点击译文会定位到对应原文。需要独立查看原页时，关闭该选项。

显示情况含义与操作
橙色句子标记可以定位到句子范围，仍需核对翻译是否准确
黄色段落标记只能可靠定位到整段，不能据此认定逐句对应
仅跳到页面，没有色块无法精确匹配文字，按页面核对原文
旧版整页文本块提示旧导入内容将整页作为一个段落，仅定位页面，避免黄色铺满整页；可靠句子仍可能单独定位
按句序对应、未经语义校验提示使用旧译文的句序和数字进行辅助匹配，不表示语义已验证

句子合并、重排、数值不一致、表格及复杂排版会影响对应。逐句重译可以改善部分定位，但不会保证跨语言语义完全一致。旧版整页文本块的提示不会自动修复原始段落粒度。

7.3 从原文跳到译文

点击 PDF 中已经建立定位关系的文字区域，可以反向定位译文。并非页面的每个区域都支持此操作。

页码、笔记或原文跳转后，使用“返回刚才的位置”回到先前阅读位置。双击原页可放大核对图表和化学结构。

7.4 查看原始 PDF

阅读区的 PDF 是页面图像，不能直接选中文字。需要复制原文、打印或使用浏览器的 PDF 功能时，点击“原始 PDF”。

8. 笔记、书签与文字批注

8.1 添加段落笔记

  1. 切换到双语或译文模式。
  2. 点击需要记录的译文段落。
  3. 点击“译文”标题旁的“记笔记”。
  4. 输入自己的想法、核对结果或实验注意事项。
  5. 点击“保存”，确认保存成功。

笔记按钮不可用时，等待文献和笔记加载完成，并确认已选中一个有译文的段落。

8.2 添加书签

在笔记窗口勾选“将此段加入书签”。可以不填写笔记内容，只保存书签。

8.3 查看、编辑与删除

顶部“我的笔记 / 书签”显示已有记录。点击记录可定位到对应段落，也可以编辑或删除。列表提供“为当前段添加笔记 / 书签”入口。

8.4 文字批注与高亮

选中一小段译文，点击出现的“为选中文字记笔记”。选区应位于同一个段落或表格单元格内，最多 350 个字符。

译文修订后，无法可靠找到原批注位置时显示“位置待核对”。笔记内容仍保留，可以从列表查看和编辑。

8.5 草稿、待同步与冲突

正在输入的笔记及人工修订会暂存在当前浏览器。重新打开后可以恢复草稿。

笔记保存失败时进入待同步队列，服务恢复后尝试补存。只有保存成功的记录才写入本机文献目录。多个页面同时修改时，可能出现版本冲突；保留输入，核对其他页面的内容后再保存。

清理浏览器数据或更换浏览器前，先保存所有草稿并处理待同步记录。复制 data 文件夹不会包含尚在浏览器中的草稿。

9. 人工修订、重译与历史恢复

先点击译文段落或小段，再使用标题旁的操作。

操作用途是否调用模型
修订当前段手工修改措辞、术语或错误否
重译当前段重新生成当前选中部分的译文是
恢复上一版恢复保留的旧文字否
逐句对齐重译重新生成带更细句子锚点的结果是

逐句布局中，当前段操作针对选中的小段。重译当前小段沿用已有译文的目标语言。历史最多保留 20 版文字。

全段重译后，“恢复原段上一版”会恢复旧段落文字并退出该段的小段布局。重译失败时保留旧译文，未完成的新结果不会替换旧段。

翻译任务进行中不能同时人工修订。先暂停或等待任务完成，再编辑，避免互相覆盖。

10. 导出与快捷键

10.1 导出译文

在阅读页使用“导出译文”，保存 Markdown 文字译文。译文支持表格、加粗、标题及部分上下标排版，导出保留文字内容。

导出不能代替原始 PDF 的图表、公式和排版，也不是完整文献备份。需要迁移笔记、修订历史和任务时，应备份整个 data 目录。

10.2 快捷键

快捷键功能
J下一段
K上一段
N为当前段记笔记
Esc关闭弹窗；没有弹窗时返回刚才的位置（有返回记录时）

输入框、编辑区域和弹窗中不会触发阅读快捷键。页面的“? 帮助”提供按主题排列的操作说明，打开帮助不调用翻译接口。

11. 数据保存、备份与升级

11.1 数据保存位置

默认情况下，免安装版在 YiRead.exe 旁创建 data 文件夹。

内容默认位置
原始 PDF、文献信息及解析内容data/library/文献编号/
已保存笔记与书签同一文献目录内的 notes.json
译文与修订历史data/translation/
翻译任务data/jobs/
存储目录配置data/config.json
翻译设置与密钥data/translator.json
启动错误日志data/startup.log
阅读偏好、进度、草稿及待同步队列当前浏览器的数据存储

如果手动配置了其他存储位置，备份时也必须包含这些实际数据目录。不要在程序运行时直接修改业务 JSON 文件。

11.2 完整备份

  1. 保存笔记和修订，确认没有待同步内容。
  2. 暂停翻译并等待请求返回。
  3. 关闭服务窗口。
  4. 复制整个 data 文件夹到独立备份位置。
  5. 为备份添加日期，例如 YiRead-data-2026-10-08。

备份包含明文 API 密钥，请妥善保管。仅复制原始 PDF 或仅导出译文，都不是完整备份。

11.3 升级应用

  1. 关闭旧版 YiRead，备份旧版 data。
  2. 将新版压缩包解压到新的可写目录。
  3. 将旧版整个 data 文件夹复制到新版 YiRead.exe 旁。
  4. 启动新版，检查文献、译文、笔记与设置。
  5. 确认资料正常后再处理旧版目录。

避免同时启动新旧两个版本。迁移到其他电脑或浏览器后，浏览器保存的阅读进度及偏好可能需要重新设置。

11.4 重新打包与分发

修改前端、后端或依赖后，需要由维护者重新生成发行包。修改测试文件本身不改变用户运行功能。

重新打包不要求先删除旧压缩包，脚本会覆盖输出；需要保留旧版时先备份。不要在打包过程中运行输出目录中的程序。

发给其他用户时，提供干净发行压缩包。不要将自己的 data 文件夹一起分发，其中可能有文献、笔记和 API 密钥。

12. 隐私与费用

导入、原页渲染、文献信息提取、阅读、人工修订和已保存笔记在本机处理。点击翻译、重译或测试连接时，相应文字会发送至自己配置的模型服务商。

API 密钥以明文保存在本机设置文件中，界面不会回显完整已保存密钥。不要公开包含密钥的设置文件、备份或截图。

免费标记可能表示限额免费层、试用或新用户额度，不能理解为无限免费。实际可用模型、价格、额度及数据政策，应在服务商平台核对。任务显示的 token 用量不是准确账单；暂停已发出的请求、失败或超时重试仍可能产生费用。

提交未公开资料前，应确认所选服务的数据处理规则。核查化学文献时，尤其注意化合物编号、收率、温度、当量、单位、试剂缩写和参考文献编号。

14. 推荐日常操作流程

阅读前：启动程序，导入文献，核对标题及标签。首次使用新模型时，先测试连接并翻译一页。

阅读中：按实际需求选择翻译范围，使用双语模式核对原文。对关键实验条件做笔记，对翻译错误进行人工修订，对需要回看的段落添加书签。

阅读后：保存笔记及修订，确认待同步内容已处理；需要共享文字时导出译文。暂停未完成任务并等待结果保存，再关闭服务。

定期维护：备份整个 data 文件夹。升级时先保留旧版数据副本，确认新版资料完整后再清理旧目录。
