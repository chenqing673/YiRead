# YiRead · 译·读

一个运行在本机的 PDF 文献阅读与翻译工具，使用 Python 标准 HTTP 服务、原生 HTML/CSS/JavaScript 和 JSON 存储。

面向合成一室，工具名为 YiRead · 译·读，页面注释为「合一文献阅读翻译助手」。首页采用紧凑标题与单行格言，优先展示文献库。每次进入、刷新或返回主页时随机更换格言，共 32 条；同一标签页内轮换完再重复，并避免连续重复。

## 快速开始

完整用户手册见 [用户使用说明书](docs/用户使用说明书.md)，包含免安装启动、翻译配置、阅读批注、备份升级和故障排查。重新打包时会将手册一起放入发行包。

普通用户使用 Windows 64 位免安装包：解压 `dist/YiRead-Windows-x64.zip`，双击其中的 `YiRead.exe`，程序自动打开浏览器。无需安装 Python 或其他依赖。使用时保留服务窗口，关闭窗口停止服务。请保留 `_internal` 文件夹；文献与设置保存在程序旁的 `data` 目录。翻译仍需配置模型服务。

开发者可安装 `requirements-build.txt` 后运行 `powershell -ExecutionPolicy Bypass -File build-portable.ps1` 重新生成发行包。打包只收集代码、前端和运行依赖，不收集个人数据。当前发行目标为 Windows 10/11 x64。

支持 Python 3.11 及以上。依赖通过 `requirements.txt` 安装；PDF 提取与页面渲染使用 PyMuPDF。

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe backend/server.py
```

已有环境时可双击 `start.cmd` 启动。浏览器访问 <http://127.0.0.1:8765>，关闭服务窗口或按 Ctrl+C 停止。

## 使用流程

1. 点击「导入 PDF」，或将 PDF 拖拽到页面。支持批量导入，单个文件上限 50 MB。
2. 在「翻译设置」选择服务商和翻译模型。预置 OpenAI、DeepSeek、通义千问、Kimi、智谱、硅基流动、Gemini、Groq、OpenRouter 和 Mistral，自动填写接口地址；点击「注册 / 登录」或「申请 API Key」打开官方平台，完成注册和密钥创建，再将密钥填回。也可以选择自定义模型或自定义 OpenAI 兼容服务，手填 API **基础地址**、模型 ID 和密钥。例如基础地址 `https://api.openai.com/v1`；程序会自动拼接 `/chat/completions`，请勿重复填写。
3. 选择目标语言（简体中文、英文或日文），保存设置。可点击「测试连接」验证服务；这会发送一条简短测试文本，可能产生服务商调用费用。本地无鉴权模型服务可留空密钥。
4. 点击「翻译全文」。文献自动排队，逐段保存结果。失败后点击「继续翻译」或「重试翻译」，复用同一目标语言的已完成段落。
5. 进入阅读页，切换双语对照、原文或译文。双语模式左侧显示原始 PDF 页面，右侧显示译文；滚动右侧或点击译文段落，左侧自动定位并用半透明色块标出对应原文。可关闭「跟随译文」自由浏览 PDF，支持页面缩放、页码跳转、译文字号调整、深浅主题、阅读进度恢复，以及 Markdown 译文导出。

旧文献保留原段落编号和已有译文，通过文字匹配定位。无法可靠匹配的段落只定位到页面并提示，不显示色块。新导入的 PDF 会保存文字坐标；原始页面中的图片、表格和公式保持原貌。

浅色块标出当前段落，深色块按译文段内的阅读进度估算原文行，左侧将该行对齐到固定阅读位置。译文长度和句序可能不同，因此深色行属于进度估算，并非逐句语义对齐。

「重新翻译」会重新请求全部段落；一般失败重试会保留并继续部分结果。修改目标语言后，新任务会使用新的目标语言。队列中的任务使用创建时选择的语言。现有模拟译文不会作为真实译文展示，请配置服务后重新翻译。

## ChatGPT 登录与模型申请

当前版本使用 API Key 翻译，不能自动复用本机 ChatGPT 客户端或浏览器的登录状态。官方提供需用户授权的 [Sign in with ChatGPT 方案](https://developers.openai.com/siwc/token-sharing-open-source/sign-in)，其模型调用需使用 [Responses 流式接口](https://developers.openai.com/siwc/token-sharing-open-source/models-and-inference)，与当前 Chat Completions 接口不同。本项目尚未接入此授权方式。

设置页为每个服务提供官方注册/登录、API Key 申请和配置指南链接。注册、账户验证、开通、付费及创建密钥由用户在官方平台完成；应用不会自动注册账户，也不保证每个账户已开通全部模型。内置名单于 2026-10-05 核对，模型 ID 和可用性以服务商控制台为准，新增模型可直接使用「自定义模型 ID」。

免费选项单独标注为「免费模型」「有免费层」「免费试用层」或「新用户免费额度」，并提供官方额度 / 价格链接。[智谱 GLM-4.7-Flash](https://www.zhipuai.cn/zh/news/148) 是免费模型；[Gemini](https://ai.google.dev/gemini-api/docs/pricing)、[Groq](https://console.groq.com/docs/rate-limits)、[OpenRouter](https://openrouter.ai/docs/guides/routing/model-variants/free) 有受限免费选项；[Mistral](https://docs.mistral.ai/getting-started/quickstarts/studio/activate-and-generate-api-key) 提供 Free mode 试用。[百炼](https://help.aliyun.com/zh/model-studio/new-free-quota) 提供北京地域指定模型的新用户额度，通常 90 天有效，建议开启「免费额度用完即停」。硅基流动的预置模型按量收费，不将合作应用的免费通道标为个人 API Key 免费。免费资格、限额及价格可能调整；切换付费层或自定义模型时须重新核对。Gemini 免费层内容可能用于改进产品，提交未公开研究资料前请确认数据政策。

切换接口地址保存时，会清除旧接口的密钥；同一接口仅更换模型时，密钥留空继续保留。阿里云预填北京地域兼容地址，其他地域和业务空间域名需按官方指南调整，并使用对应地域密钥。

## 文献管理

文献库支持即时标题与文件名搜索、按标题或导入时间排序、按翻译状态筛选。文献详情提供元数据和移入回收站操作，执行中的翻译文献暂不能删除。回收站保留原始 PDF、解析结果、译文、笔记和任务，可在文献库点击「回收站」恢复；同编号文件已存在时不覆盖。

文献库固定采用条目视图。搜索支持作者、期刊、年份、DOI 和标签，支持收藏、已读状态筛选。详情页可以编辑文献信息、课题标签，或从原始 PDF 识别信息。识别使用本机 PDF 元数据与首页文本，可能不完整，需要人工核对；不会请求外部文献数据库。重复导入按文件内容 SHA-256 检测，已有文件只返回原文献，不创建副本。

## 合成文献翻译与修订

译文阅读支持 Markdown 表格、加粗与标题，支持明确的上下标标记（如 `^{a}`、`_{6}`）、常见化学式与核磁标记（如 H2O、13C NMR）。只进行安全的文字排版，不执行模型返回的 HTML，也不自动修正数值或推测复杂公式。表格较宽时可横向滚动，导出仍保留原始译文文本。

跟随以句子为锚点：滚动或点击译句，橙色边框和左侧标记标出对应原文句子的实际文字范围，深浅主题均保留 PDF 白纸底色。取消按译文高度比例猜测原文行号。已有译文在本机尝试按句序对应并核对数字，界面会明确标注未经语义校验；句子合并、重排、数字不一致或表格等无法可靠对应的情况，仅显示黄色整段高亮。双栏定位限制在原段落区域，避免把重复句子定位到另一栏。

选中译文后可记笔记或加入书签，通过「笔记 / 书签」查看、编辑、删除及跳转。笔记保存为本机文献目录内的 `notes.json`，重启浏览器或服务后仍可使用，备份文献目录会包含笔记。原有浏览器笔记会在首次打开对应文献时迁移；迁移未完成时保留浏览器备份。多个页面同时保存时会检查版本，冲突时保留输入并提示重新核对，避免静默覆盖。旧段落拆分或恢复后优先按原文定位，无法精确匹配时回到原段首，笔记仍可从列表编辑。

翻译设置提供可编辑的合成术语表，每行如 `workup = 后处理`。提示模型保留化合物编号、试剂缩写、单位、温度、当量、收率和参考文献标号；这是提示约束，不保证模型完全遵守，重要数据应核对原文。

默认不勾选逐句翻译，按段落翻译。需要更精确的句子锚点时可在设置中开启：保存每句的原文与 PDF 坐标，极长句按约 650 字符拆成片段，识别句界时保护小数、实验数值和常见学术缩写。逐句模式可能增加请求量并减少跨句上下文。已有译文不会被自动改写；点击「逐句对齐重译」会调用当前服务重新翻译，保留旧文字历史。扫描件仍需 OCR，句序对齐不能保证跨语言语义完全一致。

阅读页点击翻译按钮，可选择全文、当前页或指定页码，默认继续未译部分。批量请求默认开启，每批最多 8 个单元、约 6000 字符，严格按原文编号匹配；缺项单独补译，不按返回顺序猜测。并发默认 1，可选择 2；限流和暂时故障有限重试，密钥或额度错误及时停止。暂停不会中断已发出的请求，会保存已返回的结果并停止派发新请求。任务显示范围内进度、整篇覆盖率、失败清单及接口返回的 token 用量，支持仅补译失败部分；不提供未经核实的费用估算。

笔记与人工修订输入会暂存在当前浏览器，重新打开后可恢复草稿。笔记保存失败时进入待同步队列，恢复本机服务后重试；重复操作不会重复创建笔记，版本冲突需要核对后再保存。草稿与待同步操作属于当前浏览器，清理浏览器数据前请先保存。

选中译文文字可添加文字批注与高亮；修订后找不到可靠位置时标记「位置待核对」，保留笔记。点击原 PDF 文字区域可定位对应译文，页码或笔记跳转后可返回刚才的位置。J / K 切换阅读段落，N 记笔记，Esc 返回；输入框内不会触发这些快捷键。双击原页可放大核对图表和化学结构。原页采用有界磁盘缓存与邻页预加载，保留原始颜色。

点击译文选中小段，可「修订当前段」「重译当前段」「恢复上一版」。修订直接保存在本机，不调用模型；重译只请求当前小段，沿用已有译文的目标语言。历史最多保留 20 版文字，原文 JSON 和段落编号不改变。全段重译后的「恢复原段上一版」会恢复旧段落文本并退出该段的小段布局。翻译进行中禁止人工修订，避免互相覆盖。失败时旧版译文保留，未完成的新小段不会替换旧段。

## 数据和隐私

- 原文结构：`data/library/{paper_id}/paper.json`
- 原始 PDF 与元数据：同目录下的 `source.pdf`、`item.json`
- 阅读笔记与书签：同目录下的 `notes.json`，包含版本信息
- 译文：`data/translation/{paper_id}.json`
- 任务：`data/jobs/{job_id}.json`
- 存储目录配置：`data/config.json`
- 翻译服务配置：`data/translator.json`

三类业务数据仍独立存储。JSON 使用原子写入。小段原文副本、定位和修订历史属于译文文件；作者、期刊、标签、收藏及已读状态属于 item.json。阅读偏好与进度保存在当前浏览器的 localStorage。

服务仅监听 `127.0.0.1`。密钥保存在本机配置文件中（明文），不会通过配置 API 回显；`data/` 已加入 `.gitignore`，请自行保管配置文件。导入和阅读均在本机进行，**点击翻译时，文献文本会发送至你配置的服务商**。API 采用 [Chat Completions 请求格式](https://developers.openai.com/api/reference/resources/chat)。实际模型可用性、计费和数据保留规则由服务商决定。

## 当前边界

- 支持含可提取文字的 PDF；扫描件需先自行 OCR。
- 提取文字时识别单栏、双栏及多栏，按每栏从上到下、从左到右读取，跨栏标题和图注用于分隔阅读区域。复杂表格或不规则排版仍可能需要人工核对。已有文献保持段落编号与笔记关联；此前已把两栏混在同一段中翻译的内容，需要重新翻译才能纠正译文。
- 阅读页将原 PDF 渲染为页面图像，保留排版，但不能直接选择其中的文字；需要复制文字或使用 PDF 自身功能时可打开「原始 PDF」。自动跟随以段落为单位，扫描件需 OCR 才能获得文字定位。
- 任务按文献串行执行，文献内请求并发限 1–2，单次模型请求超时 90 秒；服务重启会将未完成任务标记为暂停，继续时复用已保存的翻译单元。
- 未配置真实服务密钥时不能验证真实服务的翻译质量与费用。
- 已通过浏览器检查文献库、双语阅读与深浅主题；当前界面采用中性底色、低饱和蓝色和简洁的学术排版。

更多操作说明见 `docs/deployment.md`，本次修改见 `docs/changelog.md`。

文献库、阅读页与详情页均提供「? 帮助」，点击可按主题查看详细功能、操作步骤、快捷键、费用说明与常见问题。
